# Corriendo por salud

Proyecto integrador de la Unidad 2. Sitio web (solo frontend) sobre el deporte de correr.

## Páginas

| Página | Archivo | Qué tiene |
| --- | --- | --- |
| Inicio | `html/index.html` | Portada con foto, horarios, quiénes somos y distancias |
| Entrenamiento | `html/entrenamiento.html` | Planes por nivel, ritmo, técnica y tipos de entrenamiento |
| Carreras | `html/carreras.html` | Tabla de carreras con filtro por distancia |
| Consejos | `html/consejos.html` | Consejos básicos, día de carrera y preguntas frecuentes |
| Inscripción | `html/inscripcion.html` | Formulario validado con HTML5 y JavaScript |

## Tecnologías

- HTML5 semántico y CSS3
- Bootstrap 5 (grid y componentes)
- Google Fonts: Poppins
- Font Awesome (iconos)
- SweetAlert2 (alertas)
- localStorage (inscripciones)

## Paleta de colores

- Blanco `#ffffff`
- Azul `#1f3b8f`
- Rojo `#c41e1e`
- Gris claro `#f2f2f2`
