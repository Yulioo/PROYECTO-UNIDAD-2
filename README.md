# Corriendo por salud

Proyecto integrador de la Unidad 2. Sitio web (solo frontend) sobre el deporte de correr.

## Páginas

| Página | Archivo | Qué tiene |
| --- | --- | --- |
| Inicio | `html/index.html` | Presentación, noticias del grupo y horarios |
| Entrenamiento | `html/entrenamiento.html` | Sesiones de la semana y técnica |
| Carreras | `html/carreras.html` | Tabla de carreras con filtro por distancia |
| Consejos | `html/consejos.html` | Artículos con consejos para correr |
| Inscripción | `html/inscripcion.html` | Formulario validado con HTML5 y JavaScript |

## Tecnologías

- HTML5 semántico y CSS3
- Bootstrap 5 (grid y componentes)
- Fuente: Segoe UI (Microsoft) con Open Sans de Google Fonts
- SweetAlert2 (alertas)
- localStorage (inscripciones)

## Paleta de colores

- Blanco `#ffffff`
- Azul `#1f3b8f`
- Rojo `#c41e1e`
- Gris claro `#f2f2f2`
